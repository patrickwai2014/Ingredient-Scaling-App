# Ingredient Calculator

A simple web app for saving recipes and scaling the ingredient amounts to however much you want to make.

- Save recipes with ingredients, amounts, units, output amount and notes
- Enter the output you want (e.g. 20 pcs) to see the scaled amount of each ingredient
- English and Traditional Chinese (繁體中文)
- Backup / restore recipes as a JSON file
- Recipes are saved in the browser on each device

The whole app is the single `index.html` file, so it can be hosted with GitHub Pages.
